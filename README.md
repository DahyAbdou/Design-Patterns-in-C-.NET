# Design Patterns in C# / .NET

A practical and interview-focused collection of **software design patterns implemented in C#/.NET**, with clear explanations, real-world scenarios, and production-oriented examples.

The goal of this repository is not only to demonstrate how each pattern works, but also to explain **when to use it, why to use it, its trade-offs, and how it can improve maintainability, scalability, testability, and separation of concerns**.

## Patterns Covered

### Creational Patterns

* Factory Method
* Abstract Factory
* Builder
* Singleton
* Prototype

### Structural Patterns

* Adapter
* Facade
* Decorator
* Proxy
* Composite
* Bridge

### Behavioral Patterns

* Strategy
* Observer
* Command
* State
* Chain of Responsibility
* Template Method
* Mediator

## Each Pattern Includes

* Pattern definition and intent
* C# implementation
* Real-world use cases
* Practical .NET examples
* UML / architecture diagrams where useful
* Advantages and disadvantages
* Common mistakes and anti-patterns
* Comparison with related patterns
* Senior-level interview questions and answers

## Focus

The examples are designed around practical **ASP.NET Core, Web API, Clean Architecture, enterprise integrations, dependency injection, and maintainable backend systems**.

The repository is intended as both a **learning reference and a technical interview preparation guide** for .NET developers.
